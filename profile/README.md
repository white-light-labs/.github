# White Light Labs

**An experimental workspace for learning by building with AI.**

White Light Labs is where a project manager and product owner explores software development hands-on. By building custom systems and AI tools with AI-assisted development, the goal is to grow practical coding skills and become more familiar with the practices behind building and maintaining software.

## What we're exploring

- Custom systems shaped around real needs
- AI tools and AI-assisted workflows
- Coding through experimentation and iteration
- Development practices that make projects easier to understand, improve, and maintain

## The approach

These projects are part of an ongoing learning process. Each repository is a place to experiment, solve a problem, and build a clearer understanding of how software works—from the first idea through implementation and refinement.

Explore the [repositories](https://github.com/white-light-labs?tab=repositories) to see what's in progress.
